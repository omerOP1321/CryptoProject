Accessibility Statement

We are committed to making the Crypto AI Prediction website usable for everyone, including people with disabilities. We continually work to improve the accessibility of the site in line with the Israeli Equal Rights for Persons with Disabilities Regulations (2013) and the Israeli Standard IS 5568, which is based on the WCAG 2.0 Level AA guidelines.

Conformance status

The site is built to conform with WCAG 2.0 Level AA. We aim to support semantic HTML, keyboard navigation, sufficient colour contrast, descriptive link text, and assistive-technology compatibility throughout the site.

Accessibility features on this site

An accessibility menu is available on every page via the floating accessibility button in the bottom-left corner. It lets you:

  • Increase or decrease the text size
  • Switch to a high-contrast display
  • Highlight and underline all links
  • Switch to a more readable font
  • Enlarge the mouse cursor
  • Stop motion and animations
  • Reset all accessibility settings

The site also supports keyboard-only navigation and works with common screen readers.

Known limitations

Some interactive financial charts are rendered by a third-party library (TradingView Lightweight Charts). While we provide the underlying data in accessible text where possible, the charts themselves may not be fully accessible to all assistive technologies. If you need this information in another format, please contact us.

Feedback and contact

If you encounter an accessibility barrier, or need help with any part of the site, please contact our accessibility coordinator. We will make every effort to respond and to provide the information you need.
